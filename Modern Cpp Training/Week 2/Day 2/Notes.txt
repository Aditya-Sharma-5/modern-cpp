Variation of applying function -
    A) Function received is applied on all items in the data container received.We get one output per item 
            --> Map
    
    B) Function received is applied on all items in the data container received.However , we receive fewer 
       number of output than the input item count.
            --> Example : 1, 2, 3, 4, 5, 6
                Expected Output : Only show elements which are divisible by 3 

                --> Filter
                [Note : The function must be a predicate(a function that returns a bool)]
    
    C) Function received is applied on all items in the data container received. Result of previous operations
       is used for processing next item.

       REDUCE
       e.g : Summation of N items in the data container
