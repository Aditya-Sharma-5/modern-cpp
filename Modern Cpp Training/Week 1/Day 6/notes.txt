Object Oriented Programming 
    --> creating instances/data units based on model and executing functions based on type of data 
        e.g - creating 3 variables of class vehicle 
    --> class , object & inheritance are NOT MANDATORY 
        e.g - Go Programming Language 
            - no class , no object , no inheritance 
            - Go supports OOPs 
            a) Data models : STRUCT
            b) Function Receiver (pointer , value)
